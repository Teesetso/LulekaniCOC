# Lulekani Church of Christ Platform ⛪

## Project Overview
The **Lulekani Church of Christ Platform** is a dedicated community web application built to support the Church of Christ in Lulekani. It provides a digital space for outreach, information sharing, and event management, helping the congregation stay connected and engaged.

---

## 🎯 Purpose
- Create a centralized hub for church announcements, events, and resources.  
- Strengthen community engagement through accessible online tools.  
- Provide a clean, responsive platform for members of all ages.  

---

## ⚙️ Key Features
- **Announcements Board** → Share church news, updates, and devotionals.  
- **Events Management** → Organize and display upcoming services, meetings, and outreach programs.  
- **Responsive Design** → Optimized for desktop and mobile devices.  
- **Community Focus** → Built specifically for the needs of the Lulekani congregation.  

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript  
- **Design**: Responsive layout for accessibility  
- **Deployment**: Works in any modern browser
